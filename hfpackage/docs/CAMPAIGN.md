# Pack10K 对标战役配方 — 十一轮 GPT 对抗评审可复现方法

> 目标: 使参数化零售资产包在视觉上对标 NVIDIA USDCraft-10K 参照渲染。
> 结果: 四组代表样本 100% 进入打平区间 (差 ≤0.5), 均分 2.88 → 7.58 (十一轮)。
> 本文档 = 完整可复现配方。资产/渲染/门禁细节见其余文档。

## 总架构: 六层闭环

```
①作者合同 → ②LLM Author → ③编译门禁 → ④usdc+物理验证 → ⑤合同渲染 → ⑥双轨评审
     ↑______________失败回注______________│______像素框架______│
                     (作者循环)                (客观指标)    (GPT 主观打分)
```

**核心纪律: 每轮只动一个变量。** 多变量改动 = 无法归因 = 评审退化为玄学。

## ① 作者合同 (author_contract_v1.md)

- 签名契约: `build_parts(params) → [{name, verts_mm, tris, material_id, joint?}]`
- 材质白名单 (MATERIALS 集合) + 密度表 (质量推导)
- 家族语义检查 (G-F7): 瓶=轴对称+有塞; 罐=有拉环+绕Z铰链; 铰盖盒=有盖+绕X铰链

## ② LLM Author 循环

- GPT 同线程承担「作者」与「评审」双角色 (分轮次切换)
- 失败回注格式: `GATE-FAIL <编号>: <详情> (部件 <name>)`
- **合同裁决表**: 作者主动披露「哪些参数被门禁限制、实际取值」(GPT 给予工程治理认可)
- 实测: bottle 一次过; hinged v3 一次过 → v4 壁厚回注一次过; 大源码回贴需分块增量粘贴 (~3KB/块)

## ③ 编译期门禁 (author_compile.py)

| 门禁 | 检查 |
|---|---|
| G-F1 | 顶点有限非 NaN |
| G-F2 | 每部件封闭流形 (边恰两面临) |
| G-F3 | 底面 z=0 落地 |
| G-F4 | 总尺寸 vs 声明 ±1% |
| G-F5 | material_id ∈ 白名单 |
| G-F6 | 关节 parent 存在/轴向单位/主轴对齐/铰链在父 bbox |
| G-F7 | 家族语义 |

实测失败率: bottle 0 次, can 0 次, hinged 1 次 (v3 尺寸门禁)。

## ④ usdc 导出 + NVIDIA 验证器同判

- 逐刚体结构: `/Asset/Links/{body,parts}/Visuals|Collisions` + RigidBody/Mass/Collision + RevoluteJoint
- **Physx 方言** (PhysxArticulationAPI + DriveAPI) = 与 NVIDIA ds_R422 逐位同构
- **NVlabs/USDCraft 官方验证器 backend=physx → PASS 15 checks** (同判)
- 质量推导: 展开面积 × 克重 (来源注释强制), 对照 `asset_extents`/`mass`

## ⑤ 渲染合同 (render_contract.md + render_studio_v3.py)

- **黑棚架构** (终局制胜): 世界全黑 + 单一大柔光顶灯 (750W/6m) + 150m 地面近黑
  - 关键教训: 亮天穹+暗地面 = 掠射菲涅尔必然产生地平线感 (无法用灯修复, 结构性)
- 确定性取景: `world_to_camera_view` 迭代拟合 fill=0.70-0.78 (主体棱线不入边距)
- 像素框架校准: 亮度对齐 NVIDIA 参照 (暗调 47-108 区间, Δ≤10%)

## ⑥ 双轨评审

### 客观轨 (pixel_framework.py)
- 6 指标 × 每行: 亮度均值 / E1 边缘密度 / E2 方向熵 / B1 背景均匀度 / H1 直方图L1 / SSIM
- **标定方法**: 用 NVIDIA 参照渲染自身跑门禁 → 阈值 = 参照值 × 1.5
- 关键发现: E1 差 3-10 倍 (材质微细节), B1 差 = 背景风格系统差

### 主观轨 (GPT 对抗评审)
- 每轮: 对照板 (我方 vs 参照并排) + 单变量说明 + 三问 (打分/打平判定/下一杠杆)
- **冻结纪律**: 已平资产冻结未动, 保证分数变化可归因
- GPT 双角色: 作者轮 (回注修复) / 评审轮 (独立打分) — 同线程分轮次切换

## 五条研究认识 (GPT 终局沉淀)

1. **结构语义优先于渲染精修** — 纸筒无法通过摄影优化变成酒瓶
2. **工程正确性 ≠ 视觉正确性** — 物理门禁全过仍可能无法表达商品特征
3. **几何存在 ≠ 几何可见** — 已有结构需灯光/角度配合才可读
4. **材质语义本身就是资产能力** — 零几何改动的材质切换提升真实性
5. **视觉门禁必须接受反例挑战** — 数值全绿仍可能有漏检 (G-F8→G-F8b 实例)
