# 3) 剩余差距 Top3

---

## Top1. 背景仍不是真正“无缝”
这是公共问题，仍是 **P0**。

虽然 Cube 污染那种大错看起来没了，但左图普遍仍有：
- 顶部背景分界线/地平线感
- 背景与地面过渡不够自然
- 仍像“一个有背景边界的棚”，不是“消隐干净的商品棚拍”

**影响：**
- 会持续拖低所有资产的成品感
- 尤其对白色盒类/玻璃类最伤

**建议：**
- 真正改成更长的无缝 sweep/backdrop，而不是“背景板 + 地面板”的视觉效果
- 让背景过渡更平滑，至少在主体后方消掉那条线
- 把“背景分界可见性”做成图像级门禁，而不是只看场景对象是否清空
