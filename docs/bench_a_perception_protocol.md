# Benchmark A — 零售感知基准 协议 v0 (冻结于执行前)

> 继承: 上游研究仓 shelf SDG 场景合成 + YOLO 臂 (05_train_yolo_mps / run_pipeline --with-train),
> photo-dieline TDE 参数化包装资产。不另起炉灶。
> 状态: **协议冻结, 执行未开始** (渲染语料 + 训练 + 评测 ≈ 数小时 MPS 预算)。

## 任务定义

合成货架场景训练 → 真实货架照片评测的**商品检测** (YOLO)。
与 sim2real_report (几何回归, 负结果 21.8%) 是**不同任务**——检测不依赖连续值迁移,
预期更稳, 但同样按预注册判据如实判负。

## 数据

- 训练: 通用零品牌货架场景合成图 (我们的包装/酒类/设备资产排面), YOLO 格式 bbox 标签 (渲染器真值, 零人工)
- 类目: v0 取 8-12 个双轴注册的通用类 (beer_bottle / beer_can / baijiu_bottle / wine_bottle /
  whisky_bottle / vodka_bottle / gable_carton / gift_box / shopping_basket / ...)
- 评测: 真实货架照片, 人工标注上述通用类的可见实例 (品牌照只标结构类, 与资产零品牌口径一致)
- **v0.1 修订 (执行前, 2026-11-26)**: 评测集规模由 ≥30 张修订为 ≥5 张/≥150 实例。
  理由: 单标注者预算内优先保证标注质量与类目覆盖; 规模小是 v0 的诚实边界, 不冒充大评测。
  覆盖: 5 图 (白酒墙/酒铺×2/礼盒墙/酒廊) 177 实例 (wine 77 / gift 69 / baijiu 25 / whisky 3 / vodka 3)。
  per-class 报告仅含 ≥3 实例的类; whisky/vodka=3 为下限样本, 结论按弱证据披露。

## v0.1 语料规模修订 (训练前决策, 2026-11-26)

- 合成语料目标: **150 图** (初拟 300; 渲染实测 ~39s/图, 300 图 ≈ 3.2h 超出单会话预算)。
- 训练语料规模不在预注册判据内, 但如实披露: 150 图 ≈ 3700 实例框。
- 300 图语料留作 v1 扩展; 本轮结论按 150 图口径披露。

## 预注册判据

| 指标 | 判定 |
|---|---|
| 主判据 | 真实测试集 mAP@50 (通用结构类) |
| 价值成立 | mAP@50 ≥ 0.35 且跨 3+ 类有效 |
| 弱价值 | 0.20 ≤ mAP@50 < 0.35 |
| 无价值 (诚实负结果) | < 0.20 → 照实披露, 归因后列后续工作 |
| 辅助 | 按遮挡分层 (无遮挡/部分/重度) 的分层 mAP; 合成→真实 gap |

## 类目映射开放问题 (执行前必须解决, 不隐瞒)

1. 真实照片上的**品牌商品**如何映射到通用结构类 (完达山屋顶包→gable_carton)?
   方案: 标注按包装结构而非品牌; 映射表入 PROVENANCE。
2. 形态变体覆盖不足的真实类 (如 PET 瓶未建) 不纳入 v0, 防止"缺类目造成假负"。
3. 评测集标注双人/双次, 差异 >5% 的框仲裁后才入库。
