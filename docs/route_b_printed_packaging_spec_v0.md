# 路线 B 设计草案 — Brand-neutral Printed Packaging (v0, 待用户裁决)

> 状态: **提案, 未开工**。用户裁决"程序化伪标签印刷是否破零品牌戒"后按此执行。
> 参照系: NVIDIA USDCraft-10K 连伪印刷都没有 (纯程序化材质); 本子类若执行即为超出 NVIDIA 现状的增量。

## 铁律解释 (裁决焦点)

现零品牌戒四条: 不出现真实商标 / 不出现真实品牌名称 / 不复制受保护包装 / 不伪造真实商品身份。

GPT 复核判定 (gpt_benchmark_review_20261127.md): 零品牌 ≠ 零印刷。空包装本身就是特殊视觉分布
(真实零售商品大部分有包装信息)。提案:

- **允许**: 非语义伪文字块 (无意义字形), 抽象几何图形, 色带/色块, 环形图案, 图文区块排版
- **仍禁止**: 真实商标字形, 真实品牌词, 可辨认的真实商品复刻, 文字编码真实语义 (如 "MILK")
- **双标签制度**: 每件资产 metadata 标 `UNPRINTED_BRAND_NEUTRAL` 或 `PRINTED_BRAND_NEUTRAL`,
  谱系可查, 不混装

## 受控参数 (每维独立可关, G0-G4 单变量)

| 参数 | 档位 | 对应实验组 |
|---|---|---|
| 印刷覆盖率 | 低/中/高 (10/40/70% 面积) | G1 |
| 色彩数量 | 1-6 色 | G1 |
| 色彩对比 | 低/中/高 | G1 |
| 图形密度 | 稀疏/中/密集 | G2 |
| 文字形态 | 无/短线/伪文字块 | G3 |
| 标签位置 | 正面/环绕/局部 | G3 |
| 材质 | 纸标/薄膜/直接印刷 (光泽三档) | G4 |

## 实验设计 (G0-G4)

同几何/相机/光照/场景/标注, 仅印刷层变:

```
G0 = 空白包装 (现库)     G1 = +色带/色块        G2 = +抽象图案
G3 = +伪文字排版         G4 = +印刷材质差异
```

成功标准: **不是**合成图更像真图, 而是 W1 独立真实评测集上 (类无关召回@0.3 / mAP50)
相对 G0 可复现提升。预注册判据: 类无关召回@0.3 相对 G0 提升 ≥10 个百分点 → 印刷层是
域差异主因假设成立; 无提升 → 假设降级为"高频细节线索但非校准瓶颈" (与 W1 反事实诊断拼合)。

## 与 W1 诊断的拼合

W1 已证: 模型响应依赖印刷高频细节 (模糊→检测消失), 但松散框已有 82%@0.1。
即瓶颈=紧致定位+类词汇, 印刷层可能主要影响**检不检得到**, 而**检准+分对**需要路线 A 的
真实校准数据。两路线正交: B 改合成分布, A 给真实校准。B 便宜 (纯程序化, 无标注预算),
可先行。

## 成本估算

- 实现伪印刷纹理生成器: 1 轮 (贴图族+参数化, 复用 zoo badge/pack 纹理管线)
- G0-G4 语料: 每组 120 图 ×5 = 600 图渲染 (~2h Metal 串行) + 训练 5×40ep (~5×15min)
- 评测: 沿用 W1 5 图真实集 (类无关口径), 零新标注

预算未动用真实标注 → 不与路线 A 抢预算。
