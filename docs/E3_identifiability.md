# E3: 单视图可辨识性受控实验（2026-11-20，GPT 指定下次评审核心交付）

## 实验设计
- A 组: 固定几何 × 27 相机格点（焦距 28/50/85 × 俯仰 5/20/35 × 偏航 -30/0/30），6 个 gable 变体，162 张
- B 组: Oracle camera — 照片 + (focal, pitch, yaw, distance/radius) 条件化输入，同 MVE 训练集 32 epoch
- C 组（解析）: 比例 × 真值 Hb → 绝对误差下限

## 结果（raw 比例单位，勘误纪律口径）

| 量 | 值 | 含义 |
|---|---|---|
| **A 组跨视角 std** | **mean 2.55%**（W 3.7 / D 4.2 / Hr 1.1 / Ef 1.2） | 相机不确定性单独贡献的预测摆动 |
| **B 组 Oracle 相机 MAE** | **1.80%** | 相机已知后的残差 |
| A 组 MVE 留出基线（仅照片） | 4.1-6.7% | 经验误差带（现有口径） |
| 多视角均值 vs 真值 | ~2.5%（27 视角平均预测） | 跨视角平均可抵消相机噪声 |

### 逐因素分解（组间均值 std）

| 因素 | 贡献 | 说明 |
|---|---|---|
| **俯仰 pitch** | **1.67%** | 最大相机敏感源（视角决定可见坡面结构） |
| 距离 distance | 1.59% | 近距透视畸变 |
| 焦距 focal | 0.78% | 较小 |
| 偏航 yaw | 0.57% | 最小（对称盒型） |

## 四来源分解（GPT 框架，证据等级标注）

| 来源 | 贡献估计 | 证据等级 |
|---|---|---|
| 相机不确定性 | ~2.5%（B 组证实可消除至 1.8%） | **SUPPORTED**（Oracle 对照+跨视角方差双证据） |
| 尺度歧义 | 对比例任务不直接作用；绝对误差 = 比例误差×Hb | SUPPORTED（解析） |
| 模型容量+数据覆盖 | ~1.8%（B 组残差） | OBSERVED（未分离二者） |
| 不可辨识性（多解） | 未测 | UNKNOWN（需同投影异几何实验，E3-B 路径） |

## 诚实边界（PD-Guardrails C2）
1. A/B 架构不同（B 多相机 concat 头）——1.80% vs 4-7% 含架构混杂，非纯相机贡献；干净对照需同架构 ±相机消融（待做）
2. f50 臂为近距特写+浅景深（填充率按焦距自适应的副作用）——跨视角 std 含此 OOD 成分
3. 单类 gable；跨类结论待多类扩展
4. B 组 Oracle 相机在真实手机照片上需 pose 估计器提供——工程上等价于"单照片+姿态估计"产品形态

## 结论（OBSERVED 级）
单视图 4-9% 经验误差带中，**相机不确定性约占一半以上**（Oracle 可回收至 1.8%）；
剩余为模型/数据项；不可辨识性贡献未知。多视角/相机先验的价值获得首个受控实证。
