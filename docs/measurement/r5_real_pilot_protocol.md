# R5 真实数据试验协议 — Real-world Pilot V0 (冻结稿 v0.1)

> 依据: R4 咨询裁决 (2026-11-25, 会话 6b05b414) — "真实数据 Pilot: APPROVED WITH CONDITIONS"。
> 本协议为 **R5-A 工作流可行性** 阶段冻结版; R5-B (分层挑战集) / R5-C (独立验收集) 另行冻结。
> 状态: 冻结 — 修改须走变更记录并在 findings 记账。

## 0. 范围与非目标

- 目标: 验证 冻结求解器基线 + 采集/标注协议 在真实世界的**端到端可行性**, 暴露合成域无法发现的问题。
- 非目标: 总体精度认证 (样本量不足, 见 §5); 求解器调参 (调参禁令见 §4)。

## 1. 实物分层 (P01; GPT R01–R05 风险分层, 拓扑×退化风险)

| 组 | 实物类型 | 验证目标 |
|---|---|---|
| R01 | 标准长方体纸盒 | 正常对照: 尺度恢复 + 重复性 |
| R02 | 标准 gable top 屋顶包 | 参数耦合: 屋顶角/鳍高/主体 |
| R03 | 扁平/近退化包装 | 几何灵敏度: 弱可辨识参数 → 预期 MANUAL/OUT_OF_DOMAIN 行为 |
| R04 | 高反光/弱边缘包装 | 观测误差: 边缘定位误差、共享标注偏差 |
| R05 | 轻微形变实物 | 模型失配: 理想参数化 vs 实物 (失配门 rms 行为) |

首批 **5 件 (每类 1 件)**。不在模板支持范围的拓扑 → 拒绝能力测试, 不混入正常统计。

## 2. 采集协议 (P02/P03)

- 每实物 ≥3 视角, 方位圆跨度 ≥25° (NEAR_DUP 门控口径), 高度角 ≥10°;
- **关键面可见性清单**: 每实物冻结"必见关键面"表, 采集后逐面核对 (25° 只约束部分几何, 不充分);
- 每实物另拍 1 组**近重复视角** (跨度 <25°) 作 B 组对照 (预期 NEAR_DUP → MANUAL);
- 内参: 焦距/传感器记录 + 棋盘格标定 (每 session 一次); fx 误差敏感性由 B04 已冻结。

## 3. 标注协议 (P04 独立性)

- **双人独立采点**: 标注员互不可见对方结果; 第三人为仲裁;
- 采点规范冻结 (角点定义图版), 禁共享边吸附;
- 逐实物记录: 标注员 ID、采点顺序、原始坐标 (不预处理);
- 双人差值分布入账 — 超过 2px 的点强制仲裁并记录原因。

## 4. 冻结与调参禁令 (P06)

- 开发集 (R5-A 5 件) 只可用于: 协议可行性、流程缺陷、拒绝行为;
- **禁止**用开发集调求解器参数/阈值; 阈值变更须新冻结版本 + findings 记账;
- 求解器基线: 本协议对应 git tag (冻结后打), Solver 字段记录 SHA + 配置 + 种子。

## 5. 真值与不确定性 (P05; GUM 口径)

- 真尺: 记录仪器型号/分辨率; 每边 **3 次重复测量**; 参考不确定性 u_ref = 极差/√3 计算并冻结;
- 比较口径: |测得 − 参考| ≤ max(tol, k·u_ref), tol=1mm (制造容差, 冻结);
- 参考值不是绝对真值 — 结论措辞禁用"精度 X mm", 用"与参考测量的一致性"。

## 6. 受控对照组 (GPT A–F)

| 组 | 控制变量 | 预期 |
|---|---|---|
| A | 互补视角+独立标注+正确内参 | 基准 |
| B | 仅近重复视角 | NEAR_DUP → MANUAL |
| C | 仅共享采点偏置 (单人采点) | 相关误差敏感性 |
| D | 仅内参扰动 (fx×1.03) | B04 已冻结行为复现 |
| E | B+C+D 叠加 | B06 处置: 拒自动 |
| F | E + 独立互补视角 | 信息补充假设检验 (合成域 P4-C 未证实, 真实域重验) |

B–F 为 **REAL-BASED CONTROLLED**, 与 A 组分开统计, 不得混为"真实精度"证据。

## 7. 失败样本 (P07) 与产物核验 (P08)

- 主动纳入"合法但不可辨识"案例 (R03 类), 验证拒绝行为是能力而非事故;
- 除参数外核对最终产物: 由测量参数生成刀版 SVG/PDF, 与实物折叠对照 (压线/粘口/鳍位)。

## 8. 冻结字段 (每实物一条记录)

PhysicalSpecimen{id, 类型组, 状态照片} · Observation{原图, 设备/镜头, 内参, 位姿}
Annotation{标注员, 独立性, 原始坐标} · Reference{仪器, 3×重复值, u_ref}
Solver{git SHA, 配置, 种子} · Acceptance{tol=1mm, 判据版本 v0.1}
Output{theta, delivery, SVG/PDF, 门禁明细}

## 9. 结论口径 (样本量诚实性)

5 件零失败的 95% 单侧失败率上界 ≈ 45% (精确二项) — 只支持"工作流可行性"结论。
可靠性量化属 R5-C (独立代表性验收集), 数量另定。
