> 依据: R4 收口复核裁决 (2026-11-25, `gpt/round4_closure_reply.md`) — P4-B "锚点真值假设必须披露"。
> 生效: R5 真实数据执行前强制。与母本冲突时以本补充为准。

## 1. 锚点性质声明 (披露要求)

锚点不是天然真值: `z_ref = H(θ) + ν_ref`。P4-B 反例证明的是**锚点给定条件下**观测信息不足,
不证明锚点本身正确; 锚点准确性属 L6 参考测量问题, 须按独立证据链审计。

## 2. 参考锚点记录字段 (每锚点一条, 缺一不可)

| 字段 | 要求 |
|---|---|
| Anchor ID | 唯一参考锚点标识 |
| Reference Method | 尺量/卡尺/其他 (方法名) |
| Instrument ID | 测量仪器身份 |
| Calibration | 校准状态与来源 (未校准须声明) |
| Reference Value | 原始测量值 (含重复次数) |
| Reference Uncertainty | 参考测量不确定性 (u_ref 及计算方式) |
| Independence | 与图像采点是否独立 (人员/工具/基准) |
| Correlation | 与其他测量误差的相关性声明 |
| Adjudication | 参考值冲突的处理规则 |

**相关性警告**: 参考测量与图像采点共用同一把未独立校准的尺/同一组定位基准时, 误差相关,
联合协方差不得用块对角 — 相关项必须建模 (写入 ESR L6 规范)。

## 3. R5-F 拆分 (区分信息来源)

- **F1**: 仅增加互补视角 → 歧义是否收缩 (视角提供的信息);
- **F2**: 互补视角 + 独立参考测量 (含不确定性范围而非单一数值) → 歧义是否收缩 (外部物理参考提供的信息)。
- 报告口径: 完整分布与尾部 + 超容差比例 + 分实物类型 + 加入参考测量前后对比 — **不得只报中位数**
  (防"中位数改善但尾部错误仍在")。
