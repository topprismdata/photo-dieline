1. **pillow_bag 软袋参数化模板**(缺口1): 横放枕式袋, 参数 W/H/厚/印刷色块; 排面渲染用低多边形+atlas 印刷(远观), 近景hero袋才上全印刷
2. **金字塔挂架**参数化(A形4层+挂钩+挂袋)
3. **背光墙货架**参数化(层数/层高/背光/层板唇)
4. 排面生成器: 每层按色系分块+随机袋型混编+第二排露头规则
