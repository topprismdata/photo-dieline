## 对账表(逐项填自参照图)

| 维度 | 参照图真值 | 备注 |
|---|---|---|
| 色彩主调 | **彩色主导**: 每层一个色系块(左起: 黄桶薯片列→棕金袋带→蓝/绿/红/黄薯片袋块), 色块边界清晰如色带; 红招牌横带压顶 | 视觉第一杠杆=逐层色系分块, 而非单袋印刷 |
| 品类形态 | 每层族内同形态: 桶装罐列(左端)/枕式袋排面(主体)/自立袋点缀; 形态按层不混 | 袋型 3 种: 枕袋/桶罐/自立袋 |
| 密度 | 每层 20-30 排满到边, 袋袋相触, 深度 2-3 排(第二排露头) | 密度不足=假的第一信号 |
| 层高/货架 | 主参照可见 7 层, 层高 ~350-400mm, 白/银层板前缘亮唇 | 量测自照片像素(待相机标定精化) |
| 价签 | 白底标签贴**层板唇沿立面**, 红色大数字+黑字小注, 每层每段独立价(2.9/4.9/5.8/5.9/7.2/1.7...), 完全不进商品区 | 逐层独立价目已可从照片读出 |
| 灯光 | **背光墙**: 层板后墙发光(软袋呈半逆光); 顶部黑轨道+多颗射灯; 红色天花板横带 | 背光是此场景灵魂, 区别于冷柜顶灯 |
| 地面 | 灰白棋盘大砖(~600mm)+白色品牌图形地贴 | 釉面微反射 |
| 招牌 | 红底横幅**贴货架顶沿连体**(非悬空): 品牌名+兔子吉祥物+广告语"来来来 好想来 又便宜又好吃" | 广告语是私有轨素材, 公开轨整带替换 |
| 拍摄 | 手机竖拍, 平视微仰, 站位偏右(货架向左深处收敛), 手持微滚转, 透视强(近端层高大远端小) | 人位相机; 透视收敛方向与 hxl_a 相反 |
| 前景独立件 | 白色金字塔形多层挂架(A字形, 4层网篮+挂钩), 挂装袋装零食 | 独立几何, 需单独建模 |

2. **金字塔挂架**参数化(A形4层+挂钩+挂袋)

4. 排面生成器: 每层按色系分块+随机袋型混编+第二排露头规则
