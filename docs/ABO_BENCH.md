# ABO Benchmark Sim2Real 配准试点（Pilot #1，2026-11-20）

## 样本
AmazonBasics A4 复印纸箱（5 包装）：官方 L309×W274×H226mm（VERIFIED_SOURCE，英寸换算），
ABO 棚拍单实例（CC-BY 4.0）。网格叠加 → vision 标 6 角点（百分比坐标，±10px 不确定度声明）。

## 管线
官方尺寸 → rsc_rsc IR → fold_all → 顶点世界坐标自动配对（front 4 角 + 右端面远侧 2 角）
→ align.fit_camera（7 参数 LSQ，soft_l1）→ 红色轮廓叠加实拍。

## 结果
- 拟合收敛：**mean 重投影 6.93px**（6 点，256×170 图，≈宽度 2.7%）
- 参数：az 21.4° / el −1.3°（近平视 ✓ 合理）/ fov_half 50°（短焦——深度-FOV 协方差）
- 视觉叠加判定（独立 vision 核验）：**5/10**——位置尺度大致正确，侧面深度方向错位 20-40px

## 方法论判决（vision 独立核验，全部采纳）

1. **循环性**：孪生几何与拟合用同源官方尺寸 → 贴合只能证明"模型+位姿能解释照片"，
   不能独立证明尺寸真值。破解：多视角 + 独立测量 + 留出点误差。
2. **单视图深度歧义**：fov/距离协方差（本例 fov 解到 15mm 等效即证据）。
   破解：≥3 视角联合（ABO 有 other_image_id 多视角可扩展）。
3. **弱纹理角点**：纸箱边线低对比 → 关键点 ±10px 起步。
   破解：ArUco/标记角点或高对比印刷边。

## 状态

Sim2Real 配准闭环 **管线成立、定量严谨性未达**——四指标中的"轮廓误差"可用，
"尺寸误差"需去循环化（多视角+留出点+独立 GT）。

4. GPT/vision 逐件叠加复核（本试点协议）

## 施工教训
1. 凹口多边形（插盖/提手孔）角点提取：顶部真角点 = 顶区 x 极值（z 排序会抓缺口点，88px→4px）。
2. 立方比例件（长宽高相近）单视图面归属歧义 → 剔除或标记 AMBIGUOUS。
3. 自动曝光后剩余泛白：白色 bg + AgX 主体高光 p90=255 未根除，G0 门在此类样本上偏松。
