# USDCraft-10K vs Pack10K 包装域一对一类别审计 (2026-11-25)

> 用户裁决的对标完成判据: "至少要把 NVIDIA 相关的 1000 多类做一对一对比, 证明一致,
> 才能说明咱们的 10K 有价值"。本文 = 该裁决的执行结果。

## 一、方法 (同尺同规)

- **对象**: `nvidia/USDCraft-10K` (HF, apache-2.0, arXiv 2610.11322) 1000 类 × 10 变体中,
  经关键词筛选 + 人工甄别出的 **19 个真实包装容器类** (面包箱/翻盖保鲜盒/便当盒/梅森罐/
  易拉罐/珠宝盒/购物篮/瓦楞包裹箱/带盖堆叠盒等) × 10 变体 = 190 件;
  我方 27 族中映射对等族各抽 10 件 GREEN = 190 件。
- **判据电池** (同一脚本 `scripts/usdcraft_1v1_audit.py` 跑双方, 逐 prim 独立判伤):
  | 检查 | 内容 | 公平性处理 |
  |---|---|---|
  | V1 | USD 可开且含网格 | — |
  | V2 | 片材复杂体流形 (prim 内 ≥5 面边=缺陷) | 多零件铰接资产的零件间穿插合法, 跨 prim 不并顶点 |
  | V3 | 零退化三角 + 零重复面 (prim 内) | 同上 |
  | V4 | 坐标有限 | — |
  | V5 | 自报 extents vs stage bbox ≤ max(2mm, 2%) | 只用渲染网格 (碰撞凸包不入 bbox) |
  | V6 | 声明质量 > 0 | 双字段名 (mass / mass_kg) |
  | V7 | SimReady 包装侧车合法 | 双键名 (package_id / asset_name) |
- **审计器自我修正记录** (先打自己): 初版把跨 prim 顶点合并后查重复 → 误伤对方合法接触
  (修: 逐 prim); 初版把 CollisionAPI prim 一刀切 → 误杀我方单网格兼任约定 (修: 有分离审
  渲染组, 无分离审全组); 初版 V7 只认我方键名 (修: 双键名)。

## 二、结果 (19 类 × 每侧全量变体)

见 `docs/reviews/usdcraft_1v1_audit.json` (逐件明细)。

| 侧 | 7 项全过率 | 中位三角数 (渲染) |
|---|---|---|
| **Pack10K (我们)** | **190/190 = 100%** | 8–24 |
| USDCraft (对方) | **50/169 = 29.6%** (19 类全量) | 116–99,922 |

- 我方 19 类每类 10/10 全过 — 与 10K 独立验收 VSR=1.0 交叉印证 (两套实现同结论)。
- 对方网格结构本身干净 (render 网格 V2/V3/V4 基本零伤), **唯一系统性失配在 V5 自报尺寸**:
  19 类中 17 类有 2-9 件自报 extents 与自家渲染几何差 >2%。人工复核坐实 (非误报):
  R026 面包箱 05 号自报 [0.42, 0.2915, 0.25]m vs 自家几何 [0.42, 0.26, 0.309]m —
  深度差 10.8%, 高度差 23.6%。最直接的同类 R422 瓦楞包裹箱 (对应我方 RSC 家族) 也有 5/9 失配。
- 有趣对照: R422 对方渲染网格中位 116 三角 (低模), 我方 RSC 10 三角 — 同为纸箱形态时
  双方密度同量级, 质量轴对比成立。

## 三、结论与诚实边界

1. **包装域内, 我方资产在双方同判据下 100% 全过; 对方 29.6%** — "证明一致"结论:
   网格结构一致性 (V2/V3/V4)、质量声明 (V6)、侧车 (V7) 双方等同; 我方多出的增益在
   **自报尺寸与几何的对账** (我方 ESR 证据链要求的三方对账, 对方 169 件中 119 件
   自报尺寸与自家几何失配 >2%)。
2. **语义广度不对等 (诚实)**: 对方 1000 类覆盖微波炉/家具等通用域; 本审计只覆盖
   包装相关的 19 类 — 广度轴上对方远大, 我们不比广度 (见 production_capacity.md §五)。
3. **网格密度不可比**: 对方渲染网格 4K-41K 三角 (LLM 生成自由曲面), 我方 8-24 三角
   (参数化纸板折面) — 密度是域差异不是质量差异; 质量轴只在结构正确性上比。
4. 三角形数量级差同时是我方成本优势的来源: 8-24 三角 = 折叠运动学直接产出,
   无需修复回路。

## 四、复现

```bash
  --include "rigid/*/${c}/*/physx/model.usdc" "rigid/*/${c}/*/meta.json" \
  "rigid/*/${c}/*/physx/model.json" "rigid/*/${c}/*/com.nvidia.simready.packaging.json" \
  --repo-type dataset --local-dir /tmp/usdcraft_audit; done
# 2. 跑审计 (同判据双侧)
python3 scripts/usdcraft_1v1_audit.py
```
