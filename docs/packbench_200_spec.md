# PackBench-200 规格 v0.1 (WP4; R1 §3-§5 判决落地)

> 独立于 Pack10K 生产集的研究基准。核心纪律: **评测验证器与生产验证器异源** —
> 过程组用 G03-G10 修复, 评分不用 G03-G10, 用独立验收器 (独立几何解析 + 外部参照 + 隐藏负向)。

## 1. 任务集 (200 = 5×40)

| 任务 | 数量 | 验证目标 | 防作弊设计 |
|---|---:|---|---|
| T1 已知模板参数生成 | 40 | 工程执行 | 结果**分层公布**, 禁只报平均 (防模板复用刷分) |
| T2 未见参数组合 | 40 | 参数泛化 | 参数由采样器独立生成, 参赛方未见 |
| T3 未见结构/新模板需求 | 40 | 结构泛化 | 留出家族 (holdout families): 训练侧不可见 |
| T4 缺陷资产修复 | 40 | 诊断+修复 | 缺陷注入器生成 (注入点对参赛方保密) |
| T5 约束矛盾/信息不足 | 40 | **正确拒绝** | 不可行任务; 拒绝≠失败, 错误生成才是失败 |

## 2. 实验组 (EXP-01 五组 + EXP-02 消融)

| 组 | 模型 | 过程 | 回答 |
|---|---|---|---|
| A | GLM | 无 (裸模型+基础工具) | 基线 |
| B | GLM | 完整工程契约 (C1-C4) | B−A = 过程对 GLM 增益 |
| C | OpenAI | 无 | A−C = 模型差异 |
| D | OpenAI | 完整工程契约 | B−D = 同过程模型差异; B−C = 组合竞争力 |
| E | **无 LLM** | 纯确定性模板引擎 | 若 E≥B: 该类任务不需要 LLM (可发表负结果) |

EXP-02 消融: 完整过程 B 拆 C1 领域契约 / C2 正向门禁 / C3 负向探针 / C4 证据台账,
逐项移除 → 哪个组件真正贡献性能。**不许只用完整系统 vs 裸模型就声称四组件都有效**。

## 3. 公平对照条件 (冻结)

- 共享: 模板访问权限、SDK、输入信息、任务定义、外部验收器
- 固定: 模型版本+推理设置+最大时间+工具调用与 token 预算; 会话隔离; 任务顺序随机化
- 记录: 全部失败 (超时/异常退出**不剔除出分母**)
- 双口径: 等预算实验 与 实际部署成本实验 分开报告

## 4. 主指标 (禁 LLM-as-judge)

**Verified Success Rate = 独立验收成功的可行任务数 / 全部可行任务数**
+ 单列正确拒绝率 (防全拒答规避); 不可行任务 (T5) 只看拒绝正确性。
配对置信区间; 按任务族分层。验收器清单:

| 指标 | 独立测量方法 |
|---|---|
| 尺寸误差 | 独立几何解析 + Pack-Real100 外部真值 (WP1) |
| 拓扑正确性 | 连通性/闭合性/相交检查 (独立实现, 非生产 G03 代码) |
| 物理正确性 | MuJoCo CPU 静置+跌落 (独立脚本) |
| 修复成功率 | 缺陷消除且未引入新缺陷 (隐藏缺陷注入对照) |
| 错误放行率 | 隐藏负向测试 (参赛方不见的缺陷样本) |
| 可复现性 | 同输入重复运行 bit 级比对 |
| 成本 | API+计算+人工+失败重试 全记 |
| 外观质量 | 人类盲评匿名随机排序 (WP2 后启用) |

## 5. 规模与功效

首轮建议 200 任务 × 5 组 × 3 重复 = 3000 运行; **先用小预实验估方差再冻结正式规模** (未过功效分析, 不冒充最终样本量)。
