# Pack10K 渲染合同 v3（冻结）— 2026-11-25

资产适配渲染，渲染不逐家族调参。本合同定版后，任何家族渲染走同一配置；
合同变更须改本文件并全体重渲，禁止绕过。

## 引擎
- Cycles，1024×1024，192 spp，AgX + `AgX - Punchy` look
- 世界底色 (0.32, 0.34, 0.37) × 0.9

## 三点灯（功率比 100 / 30 / 45）
| 灯 | 位置 | size | 功率 | 朝向 |
|---|---|---|---|---|
| Key | (0.6, -0.9, 1.1) | 1.2 | 300 | (35°, 25°, 0) |
| Fill | (-0.9, -0.4, 0.7) | 1.6 | 90 | (50°, -35°, 0) |
| Rim | (0.2, 0.9, 0.9) | 0.9 | 135 | (60°, 160°, 0) |

## 相机
- 75mm，方位 35°，仰角 20°
- 距离：`d = max(H/2 / (tan(half_vfov) × 0.72), r_proj / sin(half_vfov) × 1.62)`
  （细高物取垂直 FOV 主导，矮胖物取包围球；目标点 = bbox 中心 × 0.92 高度）
- half_vfov = atan(18/75)

## 地面
- 无缝深灰 (0.16, 0.17, 0.18) rough 0.9，低于资产底面 2mm

## 材质
- 一律引用材质库（`/tmp/render_materials.py` 与 `authoring.validate_parts._USD_PARAMS` 同源参数）
- material_id ∈ MATERIALS 十三类；瓦楞 bump 仅 paper_kraft 且墙环件（CORRUGATED 常量）
- 禁止在家族渲染脚本内改 BSDF 参数

## 部件厚度
- solidify = board_t（纸类 0.45mm；玻璃/金属薄壳 0.12-3mm 按族参数），offset 0

## 已知边界（如实）
- 开底盒闭合态由装配导出保证；透明件 solidify 双面折射在薄壳下可接受
- 参照对照（NVIDIA USDCraft 变体）经同一合同渲染，或采用其官方渲染图并注明口径
