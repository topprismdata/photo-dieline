## 负结果存证

1. **CA+暗角后置（D3e）**: 1px 通道移位+径向暗角 → GPT "数字锐化感/重影/色边" 排序反输。真实感后置≠叠相机瑕疵, 已从管线剥离（见 post_shelf_photo.py 头注）。
2. **变体水平翻转（v13-v19 镜像字真根因）**: crop_bag 50% 翻转把印刷文字本身翻转, 平面 UV 一直清白 — 五轮 UV 追凶方向错误。
3. **厚盒 35mm（v18）**: 挡背光带+厚板感灰洗全场景; 10mm 薄盒（v22）才成立。
4. **品牌字定宽 340px（v21 首版）**: TOPPRISM 超出 1024 画布裁成 "PPRIS)" 碎片 — 必须宽度自适应。
