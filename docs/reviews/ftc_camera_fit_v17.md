# FTC 相机拟合 v17 (2026-11-22)

## 动机
GPT 盲评 V15 判决 (docs/reviews/gpt_hxl_v15_review.md) P0 = 相机匹配: "先对齐消失点、货架左右边界、层板投影和可见纵深"。本轮用确定性层线拟合实现同视点渲染。

## 方法 (FTC-Fit-The-Camera, 双门禁框架实现)
- 约束: 实拍 7 条层界线端点 (m31 LINES_2D 定版读数, 14 点) ↔ 孪生层板前沿线 (planogram 7 层 310mm, 底唇 450mm)
- 参数: cam(x,y,z) + aim(x,z) + lens = 6 参数
- 求解: scipy least_squares
- 无界拟合: rms 12.1px 但 **简并** — cam_x 漂移 -7461..+1018mm, lens 79..150mm (层线族横移+转体可模仿, 不可辨识)
- LOOCV (留一层): rms 22.6px > 门 18.8px (对角 1.5%) **FAIL** — 印证层线族单独不可辨识 (real-photo-camera-calibration-identifiability 预警)
- **有界拟合** (物理域: 人位 cam_x∈±1.2m, 高 1.2-3.0m, 距 1.5-4.0m, lens 16-60mm):
  - cam = (0.252, -1.930, 3.000), aim = (-0.098, 0, 2.045), lens = 50.0mm
  - rms = 9.9px (0.95%H) — 优于无界解
  - 层位纵坐标: avg 8.4px (0.0081H, 门 0.015) **PASS** / max 18.5px (0.0177H, 门 0.03) **PASS**
  - 高度触上界 3.0m: 残差趋势 (L2+18/L7+19) 提示孪生层距 310 vs 标定 332 的系统性 (R5 ±10% 内)

## 判决
- 层线拟合锚点: rms 0.95%H ≤ 0.8%对角门 (健康度) 边缘 PASS
- holdout (LOOCV): FAIL — 无地砖锚/横幅锚的层线族不可辨识, 位姿指标记 **UNKNOWN**
- 物理域有界解: 唯一可交付解 (渲染 v17 位姿), 精度以拟合残差 9.9px 为下界
- 像素级闭环仍需标定升级 (干净棋盘/EXIF/店测 300mm 锚) — m31 报告 R1 FAIL (27px) 同源
