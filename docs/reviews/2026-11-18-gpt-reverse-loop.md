## 三个真根因（按发现顺序）

1. **模板 polygon 绕序 → 全部 Newell 法线朝内**。z-buffer 与绕序无关所以常规渲染看着正常；debug 背面剔除一开，外壁被剔、看到的全是内表面。修：渲染器法线按"背离盒中心"外向归一（模板顶点序是 G04 门禁索引配对合同，不动模板）。
2. **零板厚理想化的共面 z-fighting**：glue 按设计折进前墙内侧，与 front 同在 y=0 平面（Δy<1e-12）。修：渲染器同面仲裁（|Δz|<0.6mm 共面时壁板 rank 0 < 粘口 rank 2 胜出）。
3. **深度插值不透视正确**：屏幕空间线性重心插值 z 对透视投影是近似（精确是 1/z 屏幕仿射）。front 大三角形与 glue 小三角形虽同平面，线性插值差可达数毫米 > 0.6mm 仲裁阈 → glue 局部胜出形成竖条。修：逐像素 `zz = 1/(Σ w_i/z_i)` 透视正确插值，同平面深度精确相等，仲裁确定性生效。
