## 量化结论

1. **风格系统差**: NVIDIA 参照 = 黑棚暗调 (亮度 47-108, 背景 B1=0.0 纯均匀零分界); 我方 = 白棚亮调 (亮度 136-176, B1 0.56-14.5 有渐变分界)。**渲染合同的系统性风格差异**, 逐资产无法修复, 需合同级切换 (暗调: 灯减半+地面近黑+低曝光)。
2. **细节密度差**: E1 边缘密度 NVIDIA 0.025-0.031 vs 我方 0.003-0.011 (3-10 倍) — 参照有材质纹理微细节与更细几何。图像门禁 G-F8/G-F8b 与此独立。
3. SSIM 0.05-0.08 = 不同渲染实现的预期值 (构图/材质实现不同, 非缺陷指标)。
