# NV960 逐对比裁决记分牌 (960 对 = 48 类 × 20)

## 统计单位与口径声明 (GPT 第5轮 P0)

- 960 对源自 480 个参考资产 (每资产 2 缩略图), **非 960 个独立资产**; 族级 (48) 为现役聚合粒度。
- 8.4pp = E1 轴胜率变化 (96.8%→88.4%), 非 99.84% 整体胜率降 8.4pp。
- 双协议公式/平局策略/差异解释: docs/nv960/protocols.md; 逐对台账含双 md5+统一分辨率对照:
  docs/nv960/evidence_ledger.json (统一 256² 重裁: 884W/4T/72L (汇总回执) → **逐轴修正后 847W/41T/72L** (全样本 88.23%, 非平局 92.17%); 负对集合不变, 37 对 WIN→TIE (E1 容差带内); 结论: 不反转, 但逐件裁决受分辨率影响)。
- 环境边界: docs/nv960/environment.json (Apple M1 Max 64GB 本地实证; Windows/CPU 未测)。
- 许可与归因: docs/nv960/licenses.json (NVIDIA USDCraft-10K Apache-2.0, 并排研究性引用)。

## ⚠️ 指标混杂撤回声明 (2026-11-26 像素级审计)

**99.84% (958W/1L) 版本已撤回。** 像素级审计 (pixel_framework 七指标阶梯) 发现: 该版 E1 优势
约 2/3 来自影棚背景板的 TexNoise 细噪 (scale 240/detail 8) 在 Sobel |>24| 阈上产生的边贡献,
而非产品本体信息。其 256² 缩略图经压缩背景颗粒丢失, 对比不对等。

诚实换轨: 全量 48 类净背景重渲 (NV960_BG_NOISE=0) + 产品侧两轮锐化, 双口径重裁决:

| 口径 | 结果 | 说明 |
|---|---|---|
| 严格四轴 (分辨率/V-gate/纹理/E1) | **90.94%** (873W/0T/87L) | 我方定义的非对称验收合同 (分辨率轴全 1024² 平; E1 为唯一负向否决轴) — 非"综合资产质量胜率" |
| 像素复合七指标 (W−L 符号) | **82.0%** (787W/125T/48L 对净胜) | 研究摘要主指标; 限定表述: 98.1% 对在 S1 锐度取更高值 / 88.4% 对在 E1 取更高值 (非"更真实/更优"主张) |

> 保留 99.84% 历史版本于 git (509f71c) 作为混杂案例教材: 单一 E1 轴 + 背景纹理 = 可被
> 无意识刷高的指标。pixel_framework 审计阶梯的价值即在此。

## 自定义 V-gate 协议对照 (F1-03 修正)

在 Pack10K 自定义 V-gate 协议 (V1-V7) 下, 480 个 NVIDIA 参考资产的全门禁通过率为
20.8%, 我方受测资产为 100%。该结果**不代表 NVIDIA 官方 SimReady 协议的通过率或失败率**
(两者为不同评价合同)。渲染观感与资产结构是互补的质量维度。

## 87 负对处置 (F1-02 修正)

严格四轴协议下的 87 个负对全量保留。负对集中于部分资产族, 其中 R887、R888、R331、
R642 合计贡献 56 个负对。单体与组合场景、产品本体边密度及其他潜在影响因素的逐件
归因尚未完成, 列为后续研究。本轮停止以提高胜率为目标的渲染优化。
