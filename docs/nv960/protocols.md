# NV960 双协议定义 v2 (GPT R6 文件级核验整改版)

协议版本: strict4-v9-asymmetric-honest + composite7-v1
统计分母声明: **两协议使用完全相同的 960 个比较对作为分母** (480 参考资产 × 2 缩略图);
指标集合、胜负判据与聚合机制不同, 结果不得互相换算, 也不得解释为同一协议的宽严版本。

## 协议 A: 严格四轴 (定位: 我方定义的**非对称验收合同**)

**非对称性声明 (F2-01, 必读)**: 本协议是我方定义的验收合同, 不是四个独立质量维度
的共同证明。本轮 960 对实验中四轴的实际裁决作用:

| 轴 | 可产生胜 | 可产生负 | 实际作用 |
|---|---|---|---|
| 分辨率 | — | — | **全 960 对双方均为 1024², 恒为 TIE** (F2-02 修正: 此前文档"2048² vs 256² 全胜"系记录错误) |
| V-gate | 其 full_pass=False → 胜 | 永不负 | 单向加分轴 |
| 纹理 | 其 has_textures=false → 胜 | 永不负 | 单向加分轴 |
| E1 | our > their | our < 0.8×their (20% 容差) | **唯一实际负向否决轴** |

聚合: 任一轴负 → LOSS; 有任一轴胜且无负 → WIN; 全轴无胜无负 → TIE。
因此本轮原生结果 873W/87L (90.94%) **等价于 "E1 未触发负向容差否决, 且 V-gate/纹理/E1
至少一项取胜" 的比例**, 不得表述为综合资产质量胜率。
E1 口径: 中心 62% 裁切, Sobel |>24| 像素占比 (verdict.py 官方实现)。

## 协议 B: 复合七指标 (定位: 像素统计全谱净优势对占比)

每图 7 指标 (同 62% 裁切): E1 / E2 方向熵 / S1 Laplacian 方差 / F1 高频 FFT 比 /
H2 亮度 std / B1 背景无缝度 / T1 灰度熵。

**精确公式 (F2-03, 与代码逐字一致)**:

正向指标 (E1/E2/S1/F1/H2/T1), a=我方, b=参考方:

```
v(a,b) = +1  若 a > b          (严格大于, 含等号则否则)
         -1  若 a < 0.85 * b   (严格小于, a == 0.85*b 归 tie)
          0  otherwise
```

反向指标 B1 (低值更好): **实现为双方取负值后代入上式**, 即 v(-a, -b)。
注意该实现对反向指标具有**非对称容差**: 容差 0.85 作用在负值域后, 等价于对原始值
要求 b > a/0.85 才判负 (例: a=100, b=90 → -100 < 0.85×(-90) = -76.5 → LOSS, 而交换
操作数定义 v_low 会判 TIE)。上轮文档中"与交换操作数定义等价"的说法**是错误的,
已删除**。本实现保留为现役口径 (B1: 223W/0T/737L), 不为发布结果反向挑选公式;
其非对称容差使 B1 负判偏严 (对我方不利方向), 不影响净胜对占比的保守性。

异常值处理: 全部指标由确定性 numpy 管线产生, 无 NaN/None; 零值按上式正常参与
(零 vs 正值 → 负; 双零 → tie)。聚合: composite = Σv ∈ [-7, +7];
composite > 0 = 净胜对; = 0 = 平; < 0 = 净负对。七指标等权, 无阈值门。

## 统一 256² 公平对照 (P0-3, 修正版)

双侧 LANCZOS 统一 256² 后**重新执行完整四轴聚合** (分辨率轴重算 → 仍 TIE;
