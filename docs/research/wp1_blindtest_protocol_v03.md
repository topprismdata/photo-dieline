## 1. 命名与范围

**WP1-Pilot-100**：100 个管线未见过的真实 SKU，测量参数化结构家族的结构覆盖率与一次编译质量。编译器版本、家族版本、生成配置、门禁版本全部冻结（§5）。

## 2. 七种终态（冻结）

| 终态 | 定义 |
|---|---|
| SUCCESS | 命中家族且全部门禁 PASS（含 VALIDATION 项完成）|
| GATE_FAIL | 命中家族但任一已运行门禁 FAIL |
| OUT_OF_SCOPE | 结构不属于预先冻结的产品适用域（登记，不计入分母）|
| FAMILY_ADAPTATION_REQUIRED | 命中家族但需修改家族模板才能生成（改造轮次单独记账）|
| INSUFFICIENT_SPEC | 规格缺失关键字段（登记字段清单）|
| COVERAGE_GAP | 规格充分但无家族命中（结构签样）|
| INSUFFICIENT_SPEC | 真实商品输入规格不足（关键尺寸/结构字段缺失）——**能力缺口主测点之一** |
| COVERAGE_GAP | 规格充分但 77 家族无法覆盖该结构——**能力缺口主测点之二** |
| VALIDATION_PENDING | 编译成功但官方验证器/物理实测未完成（环境门；不得以自研门禁替代计入成功）|
| NOT_APPLICABLE | 契约项对该商品不适用（如无铰接结构的铰接门禁；无实测质量数据的质量验证）|

## 3. 四主指标（冻结定义；不再仅报告命中率）

| 指标 | 定义 | 分母 |
|---|---|---|
| M1 结构覆盖率 | 命中已知结构家族的样本数 | 100 − OUT_OF_SCOPE 数 |
| M2 一次通过率 | 首次编译即 SUCCESS 的样本数 / 命中样本数 | M1 分母 |
| M3 交付单位成本 C_delivered | 全部样本实际成本总和 / 成功交付资产数 | SUCCESS 终态数 |
| M4 物理/验证完备率 | (SUCCESS − VALIDATION_PENDING) / M1 分母 | M1 分母 |

- 逐件成本：C_i = r_h·t_h,i + r_m·t_m,i + C_ext,i；费率 r_h/r_m 与外部服务费**在冻结日登记**（R09-05 P0-07）。失败样本成本计入总和（防"只统计成功件拉低成本"）。
- 置信区间：精确二项 95%（n<150）。

## 4. 真实商品一致性门禁（P0-04，冻结）

| 门禁 | 阈值（冻结） | 说明 |
|---|---|---|
| DIM-01 尺寸一致 | 声明尺寸 vs 参数化生成 bbox：逐轴 ≤ max(1mm, 1%)（G-F4 同口径）| 阈值先于实验冻结 |
| QUAL-01 质量属性 | 仅有真实实测数据的商品才进入质量验证；无数据 → NOT_APPLICABLE | 不得宣称"质量已按真实商品验证" |
| ART-01 铰接 | 有铰接结构 → 铰接门禁；无 → NOT_APPLICABLE | 不得强制 |
| PRINT-01 印刷 | 翻转面角若落于印刷墨水区 → PRINT_MIRROR_RISK（诊断纹理或逐角映射证据）| 沿 A3-05 口径 |

## 5. 合法输入冻结与盲测隔离（P0-05）

冻结项（冻结日哈希登记）：编译器 commit、77 家族版本、生成配置、门禁版本、本协议版本。
盲测样本清单由持样方在编译器冻结**之前**生成并对执行侧保密；执行侧仅接收匿名规格（必需尺寸字段）。

## 6. VALIDATION_PENDING 语义（P0-08）

NVIDIA 验证器 / 物理实测未完成的样本登记 VALIDATION_PENDING；本地自研门禁结果单独记录，**不得替代官方验证计入 M4**。

## 6A. 分层随机抽样规则（v0.3 完整登记，P0-05 落实）

1. **分层**：按真实商品的两个正交属性分层：品类（ beverage/dairy/home ...）× 包装形态（brick/gable/tuck/...）。层 = 品类 × 形态非空组合。
2. **层内配额**：每层按其在真实商品总体中的占比分配配额（比例分配），最少 2 件/非空层。
3. **层内抽样**：简单随机（`random.sample`，seed=冻结日登记的全局种子）。
4. **排除规则**（登记为 OUT_OF_SCOPE 候选）：关键尺寸字段（≥3 轴或 D×W×H）缺失；规格字段类型异常且持样方确认不可修复。
5. **保密与隔离**：持样方在**编译器冻结前**生成样本清单（含 SKU 哈希）交 GPT 保管；执行侧仅接收逐件匿名规格包（无 SKU 号、无品牌）；实验后按哈希对账。
6. **泄漏检查**：执行侧声明其 77 家族设计与调参从未接触过持样方商品库（书面），并提交家族训练数据来源清单供 GPT 抽查。
