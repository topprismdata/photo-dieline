## R51-E 时间维度契约修正案 (R51 终裁 APPROVED_WITH_CORRECTIONS 义务)

### 修正 1: 触发事件 ≠ 事实认定

| 触发事件 | 应采取动作 | 不应自动认定 |
|---|---|---|
| 文档 Version bump | 检查字段级变化 | 商品包装已改变 |
| 快照哈希漂移 | 检查正文及属性差异 | 全部绑定失效 |
| 来源下架 | 降低来源可复核性, 保留历史快照 | 原事实必然错误 |
| 包装几何改变 | 重验尺寸/容量/陈列/物理资格 | 商品身份必然改变 |
| 印刷图案改变 | 重验印刷与商业视觉 | 几何必然改变 |
| valid_until 到期 | 标记证据 STALE, 触发复核 | 历史证据被证伪 |

### 修正 2: 三种时间状态分列 (不自动互推)

| 状态 | 内容 | 性质 |
|---|---|---|
| 证据有效性 | 来源/版本/获取时间/复核状态 | 影响, 但不自动等价于下两项 |
| 商品事实有效性 | 身份/包装规格/属性实际适用时间 | 影响, 但不自动等价于另两项 |
| 资产任务适用性 | T1~T5 分别判断是否需重验 | 分任务独立 |

### 修正 3: 工作流状态 vs 实质裁决区分

R51 报告"金典 binding_status=UNRESOLVED 未动"是工作流状态登记; 实质裁决依 R49 终裁 (EVIDENCE_INSUFFICIENT 结项)。两者不混写; 只登记状态迁移依据, 不修改历史冻结记录。
