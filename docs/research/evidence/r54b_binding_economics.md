## 必须回答的经济性问题 (R54 任务书原文)

**Q: 商品文档已提供可信 67×67×116mm 规格, 业务需求仅为固定朝向单排容量计算 — 为什么还要支付完整几何编译及质量门禁成本?**

**A (R53-B 四组对照实证): 没有必要。**
- D 组 (文档 BBox 代理) 六场景 6/6 与解析参考一致; C 组 (适配件) 5/6 (133.8mm 反例溢出 +1)
- 编译路径的边际贡献为负 (边界场景反而翻转决策) 或为零 (其余五场景)
- 成本方向: D 零编译零资产零测量; C 需一次编译 + 门禁链复跑 + 独立测量 + (本例) 探针与作废件返工

**结论: 直接规格计算应作为 T1 类任务的默认路径; 三维资产编译器不应作为所有业务的强制前置环节。** 精确 ROI 不可给出 (人工时间 NOT_RECORDED), 但方向性结论已由决策一致性证据支撑。
