# RWI 三阶段研究总汇报（L1 / L2 / L3）

日期: 2026-11-28 | 依据: R18 收口裁决 / R45 L2 冻结终裁 / R54 最终签发 + 各阶段证据归档

## 一、总览

| 阶段 | 研究目标 | 核心知识产出 | 终裁 |
|---|---|---|---|
| **L1** 规模化生产 | 参数化资产编译能力 | **生产契约与质量治理** | G2 技术目标验收通过（R18，治理偏差登记接受） |
| **L2** 消费验证 | 资产对不同业务的价值 | **任务导向保真度框架** | FINAL DOCUMENT FREEZE 通过（R45，附 8 项修正验收） |
| **L3** 可信绑定 | 真实商品↔数字资产绑定 | **证据治理 + 最低充分表示 + 决策一致性** | APPROVED WITH LIMITATIONS，7.3/10（R54），阶段关闭 |

三次认知升级贯穿全程：**能生成什么 → 业务真正需要什么 → 怎样以充分且可信的表示解决业务问题**。

## 二、L1：规模化参数化资产能力（收口于 R18）

**做了什么**：参数化编译管线（author_compile 门禁 → NVIDIA 原版验证器 → 8 文件打包契约 → 下游落体/铰接评测 → 一体化审计）；DIM-01 九件候选尺寸验证、NVSDK 九件实跑、八终态语义映射。

**规模成果**：77 个发行家族、**9,386 件冻结资产**（全程零重编译，git 历史可证）。

**关键教训**：
- 九件 SUCCESS ≠ 物理仿真已跑——NOT_RUN 按八终态定义诚实保留，不得擅自解释（R18 明文）
- 治理偏差登记制度在此建立：技术验收与治理事件分列，偏差不掩盖、接受并登记

**L1 真实含义（L3 总报告修正表述）**：成果 = 可检索结构资产集合 + 参数化生产能力的验证，
**不是** 9,386 个已绑定真实商品的数字孪生——这一定性修正直接导向 L2/L3 的问题。

## 三、L2：资产业务消费价值（冻结于 R45）

**做了什么**：WP-L2-05 SimReady 工程研究（milk_bottle_1000 + MuJoCo 适配路径，限定范围不外推），
建立 **S1–S4 成熟度阶梯**：

| 级 | 能力 | 终态 |
|---|---|---|
| S1 | 能加载（USD/单位/包围盒） | REPORTED PASS |
| S2 | 能参与动态任务（落地/推挤/堆叠） | REPORTED PASS（不代表响应正确） |
| S3 | 能正确接触 | **NOT_ESTABLISHED**（穿透 6.88–9.35mm；碰撞表示对照未完成） |
| S4 | 能可信模拟真实商品 | **BLOCKED**（缺独立物理参数与实际行为真值） |

**诚实负结果（全部保留原貌）**：2N 推力标定失配→瓶飞出 12m 翻倒 82.5°（荒谬结果照登），
0.2N 比例修正复测 1.1mm 合理；材质粗糙度条纹 AREA 10mm/5mm 两轮均不可辨（光源尺寸假设证伪）。

**协议偏离登记制度成熟**：G3-L 早于 G2-M2 送审（时序违反，PROTOCOL_DEVIATION_REGISTERED）、
50mm vs 105mm 落差口径混用（和解、双值保留）。

**核心结论**：**资产合规 ≠ 业务验证**——不同消费任务需要不同保真度，统一"最高保真"目标不成立。

**R45 拦截事件**：GPT 发现研究对象不一致（采购金典 250ml 砖盒，绑定的却是 milk_bottle_1000 奶瓶），
采购前必须解决——该矛盾直接催生了 L3 的商品级证据绑定研究路线。

## 四、L3：真实商品可信绑定（R48–R54，已收口）

七轮链：无实物→文档轨道（R48）→ 金典取证诚实结项（R49 EVIDENCE_INSUFFICIENT）→
正控设计 Coke 330ml（R50）→ 判定契约+首绑拒绝（R51）→ 参数化适配 BINDING_ACCEPTED（R52，仅外尺寸层）→
家族资格+T1 四组对照（R53）→ 时间回归 4/4+经济性+总报告（R54 APPROVED WITH LIMITATIONS）。

**核心发现**：F-L3-001 BBox≠结构等价；F-L3-002 容差通过≠决策一致（0.14mm 之差使 133.8mm 货架容量翻面）；
**NEG-T1-MSR：规格直算 6/6 胜适配件 5/6——编译器不是 T1 类任务的强制前置**；
NEG-T1-MSR 被终裁特别认可："能证明技术何时无效，同样是研发体系的能力"。

**五项架构原则 v1.0（签发）**：真实知识优先 / 任务导向保真 / 最低充分表示 / 独立业务验收 / 时间有效性治理。

**战略定位修正（终裁采纳）**：零售数字资产生成平台 → **零售任务驱动的数字表示引擎**——
3D 资产是重要能力，不是全部业务的必要前提；"何时不需要生成资产"与"如何生成"同等重要。

## 五、治理体系演进（三阶段沉淀的可复用制度）

| 制度 | 建立于 | 内容 |
|---|---|---|
| 判决原文归档 | L1 | 每轮 GPT 终裁全文存档（gpt_rXX_verdict.md，共 50+ 份） |
| 八终态语义 | L1 | SUCCESS/PASS/NOT_RUN/BLOCKED 等终态不得擅自解释 |
| 质量基线冻结 | L1→L2 | RWI-QUALITY-BASELINE-V1.0-FINAL，15 件证据哈希冻结 |
| 协议偏离登记 | L2 | 时序/口径偏离照登不掩盖，历史结果保留 |
| S 阶梯限定范围 | L2 | REPORTED PASS ≠ ESTABLISHED，限定不外推 |
| 负证据制度 | L3 | 作废件 sha256 登记（VOID_REGISTER）供复核 |
| 两类预算纪律 | L3 | 运行预算（编译/探针）与产物预算（候选/发行）不可互替 |

## 八、一句话总评

三阶段走过一条完整的认知修正曲线：先证明能大规模造资产（L1），
再发现"合规资产"不等于"业务可用"（L2），最后证明某些业务上最正确的工程决策是**不生成资产**（L3）——
9,386 件资产仍然重要，但更重要的是现在清楚地知道**该如何使用它们，以及什么时候不该使用**。
