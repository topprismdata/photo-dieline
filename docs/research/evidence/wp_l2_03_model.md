## 业务层次 (防目标偏移)

L1 消费者需求 → L2 商品组合决策 → L3 空间与陈列决策 → L4 现实执行验证。
**RWI 资产仅直接作用于 L3/L4**; 不得因空间求解提升宣称 L1/L2 (消费者需求/组合推荐/销售优化) 能力提升 — 供给约束≠消费者需求。

## 四组对照实验 (A/B/C/D)

A 品类粗尺寸 (传统) → B 精确三轴 BBox → C BBox+RWI 实际几何 → D C+陈列规则与真实场景。
**A→B 与 B→C 增量必测**; "BBox 已足够规则纸盒" 的负结果必须接受。

## 七项业务指标

可执行率 / 假可行率 / 假不可行率 / 容量利用率 / 约束违反数 / 调整成本 / 决策稳定性。

## 业务成立条件

≥1: 降错误可行方案 / 降人工调整成本 / 升真实空间利用率 / 同质量更快。禁止目标函数提升=业务成立。
