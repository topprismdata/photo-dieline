## 修正案正文 (逐门禁)

**F01 业务任务专一化**: 首轮业务任务单一化 = "零售运营人员构建、查看及调整一个实体门店乳品冷藏柜货架的数字孪生场景"。不含电商虚拟货架/营销图/物理仿真/消费者交互 (R32 §三 范围批准延续)。

**F03 基线拆分**: B1 实际工时测量 (优先) = 人工 CG 制作同一货架任务实测 (招募 1 名 CG 从业者按同一交付规格制作, 计入导入/准备/装配/调整全流程); B2 商业报价 (并行征询, 明确同一交付规格); B3 工程估算 (工时单价×复杂度推算, 仅作初步假设)。**B3 不得替代 B1; 50% 门槛结论仅在 B1 成立时签发, 否则 EVIDENCE_INSUFFICIENT**。Cold Start (商品资料进入未绑定) 与 Warm Start (资产可复用) 两情景分别测量, 结论分开登记。

**F05 照片仅视觉声明**: 真实货架照片仅支持视觉布景核对, 不作尺寸/约束证据; 尺寸证据 = 业务登记规格 (来源标注) + 场景契约约束校验。

**F07 交付物等价**: A (RWI) 与 B (人工 CG) 交付物规格等价清单冻结 = 同一货架 fixture + 同 12 SKU 身份绑定放置清单 + 可交互 3D 场景文件 + 渲染图 ×3 视角; B 路线交付缺项 → 工时补齐计入。

**F08 完整公式**: 装配成本 = Σ(人工工时×费率) + Σ(机器时间×算力单价) + 资产授权成本 (如适用); 场景变更工时 = 变更动作起至校验通过的全程壁钟; 可执行率 = 实际可陈列 placement / 方案 placement; 假可行率 = 求解可行∧实际不可行 / 求解可行; 假不可行率对称; 容量利用率 = Σ(span)/可用层长; 覆盖率 = 达标 SKU / 需求分母 (分母保留纪律: 无绑定不入场景但留在分母)。

**F09 联合门槛 (R32 §5.1 采纳)**: 硬门禁 (不可被成本收益抵消): 需求清单保留 100% + 已入场景身份可追溯 100% + fixture/场景版本绑定 100% + 硬空间约束违反 0。业务门槛: 任务适用覆盖率 ≥90%。质量门槛: 盲评 ≥7/10。经济门槛: 首建成本降 ≥50% (B1 口径)。效率门槛: 变更工时降 ≥50%。裁决规则: VALIDATED / CONDITIONALLY_VALIDATED (30-50% 且其余质量成立且成本证据真实) / NOT VALIDATED / EVIDENCE_INSUFFICIENT (仅估算)。

**F10 具体预算**: 时间 = WP-01 占 L2 8 周时间盒内 ≤3 周 (已用 1); 人工 = 执行侧 1 人; 算力 = 本机 Blender/M 系列; 停止条件 = 工程原型两轮修复仍 <90% 门禁 → 负结果结项; B1 招募失败 >2 周 → EVIDENCE_INSUFFICIENT 登记。

**F11 Rubric+隔离**: 盲评 Rubric 冻结 = 零售陈列规划评审用途 5 维 (空间排列 6.5/货架表达 4.0/身份可辨识/结构差异/整体可用性, 权重等分 v1, 评审前冻结); 评审者 ≥3 (GPT 多会话+人工), 隐藏生成路线; 评审样本 = 统一渲染视角 ×3。

**F06 哈希锁定实测**: 11/12 资产逐 sha256 已锁 (r33_f06_coverage.json f06_hash_lock; 8 冻结集 + 3 hfpackage 引用), 场景契约随附。

## BUSINESS-PILOT-20 需求优先采样设计 (R32 §2.2 采纳)

- **需求分母先行**: 从真实零售业务出发定 20 SKU 目标商品清单 (乳品冷藏柜完整单层真实组合扩展: 冷柜全 5 层→取 2 层 20 面), 清单基于公开在售伊利系乳品 (渠道: web-product-photo-sourcing 已验证管线), 商品属性=名称/规格/包装形态/公开尺寸
- **原始分母保留**: 20 SKU 全部进入分母, 不得事后替换; 逐件 5 状态登记 (SKU_EXACT/GEOMETRY_EQUIVALENT/APPROXIMATED/UNSUPPORTED/IDENTITY_UNRESOLVED)
- **资产匹配后置**: 清单冻结后才做资产匹配; UNSUPPORTED 不剔除不替换, 留分母并计入覆盖率分子分母
- **首批分配预计** (基于 L1 覆盖): 无菌砖系 SKU_EXACT/GEOMETRY_EQUIVALENT ~60%, 瓶/杯 APPROXIMATED ~25%, UNSUPPORTED (异形/组合装) ~15% — 实测后以真实数字替代
- **身份绑定**: 每件 placement 强绑定 asset_id+sha256; 无绑定不入场景但留分母

## 附: 两个价值来源观察框架 (R32 指令)

- 规模化资产生产价值 = 新增商品进入数字世界的成本 (Cold Start 单 SKU 增量)
- 持续场景维护价值 = 变化时更新成本 (Warm Start 四动作壁钟, R32 已实测毫秒级)
- 全程分别登记, 不合并宣称
