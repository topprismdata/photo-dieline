## 一、对标事实修正（R01）

- NVIDIA UsdCraft **同为程序化路线**：AI Agent 编写 Python 资产程序 → 渲染反馈与几何测量修正 → 编译为 USD/URDF；文字/参考图可直接输入，不依赖扫描。
- 真实差异不在"扫描 vs 无扫描"，而在押注维度：
  - UsdCraft-10K：**类别广度**（1,000 类 × 变体；8,222 件带关节；每物体最多 59 刚体部件/32 关节）。
  - 本项目：**零售深度**（77 结构家族 × 9,386 SKU，逐件过验证）。
- 用资产总数直接对比会掩盖上述差异。

## 三、定位（共识）

- 采用：**面向零售行业的数字资产编译器**（Retail Digital Asset Compiler）：行业结构知识 + 商品主数据 → 参数化编译与质量验证 → 标准化零售数字资产。
- 否决："中国版 UsdCraft"、"全球首个参数化零售资产库"、"全面超越 NVIDIA"。
- 长期蓝图：**Retail World Intelligence** 五层（L1 资产库[当前] → L2 行业知识 → L3 数字孪生 → L4 决策智能 → L5 执行与持续学习）。资产库是第一个独立成立、可交付、可经营、可接受国际检验的产品。
- 工程原则：**统一行业语义、统一资产契约、多种成熟生成后端、独立质量验证**。生成器可替换；行业知识、商品证据、资产身份、质量标准持续积累。

## 四、考核指标转向

从资产数量转向：未知商品生成能力、行业知识覆盖率（分母=真实行业需求，非家族数）、单位生产成本、物理真实性、实际业务收益。**不建议立即扩展到 100,000 SKU。**

本摘要基于检索与源码阅读；尚未逐件下载复测各方资产、未独立核验本项目 9,386 SKU 全量、未确认 HF 完整发布清单。可做技术路线与战略定位评价，不能做全球领先性认证。
